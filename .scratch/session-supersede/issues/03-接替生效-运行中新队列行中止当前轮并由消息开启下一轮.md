# 03: 接替生效：运行中新队列行中止当前轮并由消息开启下一轮

**What to build:** 把开关、判定核心和会话门面接起来：开关打开且该会话正在运行，用户在运行中提交的消息一旦出现在 `next-turn` 队列，立即调用该会话的取消，当前轮结束、这条消息保留并开启下一轮。触发点只认持久化后的队列行，不在发送时乐观触发。每个会话同时最多一次取消在飞，落定后清标志；同一行绝不取消两次。开关关闭或会话空闲时，消息照旧排队、不取消。取消失败只清标志并在控制台留痕，不重试（用户可见提示留给下一张票）。开关关闭后立即恢复原排队行为。

**Blocked by:** #01, #02

**Status:** resolved

- [ ] 开启 + 运行中发一条消息：当前轮结束，队列行保留，该消息随即开启下一轮，无需再按 Esc。
- [ ] 同一队列行导致的多次渲染/求值只产生一次取消。
- [ ] 下一轮跑起来后再发新消息 → 再取消一次（latest wins）；取消还没落定时再发，不会叠第二次取消。
- [ ] 关闭开关后运行中发消息 → 纯排队，当前轮不受影响；空闲时发消息与原生行为完全一致。
- [ ] 取消失败：消息仍在队列、标志已清、控制台有记录、无自动重试。
- [ ] 接替不新增模型请求、不改写用户提示词；未改任何核心包。
